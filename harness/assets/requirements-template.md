# Requirements template — defaults every brief inherits

Only things no automated check already covers.

- T1. Free-plan / current-plan behaviour is visible, not implied.
- T2. The empty or blocked case is designed, not just the happy path.
- T3. What happens *after* the primary action is stated.
- T4. Copy says what the user gets, not what the system does.
- T5. Every state the screen can be in is named in the checklist.
