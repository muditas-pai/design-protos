# backgrounds

Saturated full-bleed backgrounds for page furniture — supplied art, never generated.

| file | size | reads as | use it for |
|---|---|---|---|
| `footer-saturated-blue.png` | 1440 × 900 | deep Brand-Blue wash, vertical ribs, lit from the lower right | **page footers.** Saturated Brand Blue puts it in the growth register (DESIGN.md §2, three heroes) — a footer selling or closing something. Not for app-register chrome |

## Picking rule

A background here is a *surface*, not decoration: text sitting on it must be light ink
and clear contrast, and the section takes no second competing fill. One saturated
background per page — a footer wearing this while a hero wears another is two loud
regions. If the register is app-calm, this folder has nothing for you; use the
published surface tokens instead.
