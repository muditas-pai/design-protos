Icon sizes

Icons have no size of their own today — Phosphor is a font, so each one inherits whatever font-size its parent happens to have. A button icon is 14px because button text is 14px, not because anyone chose 14. Two sizes now: 16 for an icon beside a label, 20 for one that is the whole control. Left is what inheritance produces; right is naming it.
