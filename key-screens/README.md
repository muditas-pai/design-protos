# key-screens

Canonical screens that mirror the **live product** — the reference frames everyone duplicates
from. Planned: **dashboard · editor · login · pricing**.

- **Treat as read-only.** To explore, copy a screen into your `explorations/<you>/` and riff there.
- Each screen is built with the design system and carries a sync stamp at the top:
  `<!-- synced from <app route> · <date> · <owner> -->`.
- Deliberate changes go via **branch + PR** (these are shared references with blast radius).
- To refresh a screen against the live app, ask Claude: *"re-sync the &lt;screen&gt; key screen
  from pitchdeckdoclist"* — it re-derives the screen from the current app source and bumps the stamp.

_Screens get added here as they're built — they're not in place yet._
