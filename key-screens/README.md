# key-screens

Canonical screens that mirror the **live product** — the reference frames everyone duplicates
from. Each is **hand-built and hand-maintained by its owner** (the app → HTML translation is too
lossy to auto-sync, so keeping these current is a manual design job).

| Screen | Owner |
|---|---|
| editor | Mudita (`@muditas-pai`) |
| dashboard | Tyo (`@tyo-pai`) |
| pricing | Mani (`@manivasakan-arch`) |
| login | Mudita (`@muditas-pai`) |

- **Treat as read-only unless it's yours.** To explore, copy a screen into your
  `explorations/<you>/` and riff there. Want a change to a screen you don't own? Ask its owner.
- The owner keeps their screen current by hand and is the only one who edits it. They can commit
  it straight to `main` (it's theirs).
- Each screen carries a stamp at the top:
  `<!-- key screen: <name> · owner: <name> · updated: <date> -->`.

_Screens get added here as their owners build them — they're not in place yet._
