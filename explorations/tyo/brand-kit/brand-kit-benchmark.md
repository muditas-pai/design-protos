## Pitch — Team library
![Pitch team library](assets/pitch-team-library.png)
- Brand tone to setup voice guideline (FREE)
- Fonts (FREE)
- Images (FREE)
- Video (PREMIUM)
- Template can create from existing template/file or create new (FREE)
	- Create new we can simply drop the domain link and then it will automatically fetch (I think they use brandfetch):
		- Accent color
		- Images
		- Font styling
	- Template has dedicated file
