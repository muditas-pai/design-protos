Editor icon swap

The editor renders icons three different ways and only one of them is the Phosphor pack we standardise on. This is the full list of what to change, where it lives, and what it becomes. Every glyph below is rendered from the real font files, so the icon you see in the right-hand column is the icon you will get.

40icons to change
36swap to a Phosphor glyph
4become text buttons instead
3delivery methods to collapse into one

The work, in three parts

1

Delete the appicon font

appicon.woff is a custom icon font with 699 glyphs, unrelated to Phosphor. In the editor it owns the slide right-click menu, the text element toolbar, the text properties panel and the image element toolbar. Every one of its glyphs has a Phosphor replacement listed below.

Heads up on the class names: several no longer describe what they draw. ic_trim_video renders Cut, ic_save_slide_as_template renders Paste, ic_file renders Copy. Go by the described action, not the class name.

2

Move the SVG icons onto the Phosphor font, at one weight

The editor's SVG icons are legacy phosphor-react markup: a 256 background rect plus stroked paths. That is the old delivery, not the font in design-system/icons.

Weight is inconsistent within a single screen: 11 icons carry stroke-width="24" (bold) and 35 carry stroke-width="16" (regular). Everything goes to regular. Sizes are spread across 12, 16, 18 and 20 px against a steady 20 px on the dashboard; settle on one scale rather than four.

3

Move slide status off loose SVG files

The five status icons are <img> tags pointing at /docs/assets/images/status/. Their colour is baked into each file, so it cannot follow a token or respond to theme. Phosphor covers all five; set the colour in CSS.

Same command, two icons

Duplicate slide appears in the right-click menu and in the bottom bar overflow menu, drawn from a different pack in each. Both must land on ph-cards-three, which means the bottom bar menu changes too even though it is already Phosphor today.

One control changes shape, not just its icon

The text case row in Text properties is the only item here that is not a straight icon swap. Phosphor has no uppercase, title case or lowercase icon, so the four buttons become text instead, the way Figma and Google Docs do it. Behaviour is unchanged, only the button contents.

uppercase
titlecase
lowercase
After, four text buttons
NoneAA Aaaa

This is what makes part 1 finishable. Keep these as glyphs and appicon.woff ships forever for four icons.
