Round 3 · Brand-kit-themed prompt box

Branching off Option 1 (the toolbar pill) toward something much more visual — the prompt box itself wears the kit. Eight ways to theme it: solid & pale bands, a kit-coloured stroke around the whole box, a colour glow, a pale wash, a themed input outline, a left accent rail. All Coca-Cola.

Cumulative spec: faithful prompt chrome · Coca-Cola kit. This round relaxes monochrome for kit-coloured surfaces (that’s the brand-theming intent) — but Create stays ink (action). Where a band carries the kit identity, the toolbar drops the kit pill; the strokes/glows/washes keep the pill as the switch.
