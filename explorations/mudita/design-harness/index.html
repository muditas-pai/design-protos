Design harness

Candidate anchor screens for the design harness. Built from Figma, on the design system, each one filling the viewport so it can be annotated at any window size.

These are candidates, not the bank. A screen earns a row in harness/run-assets/exemplars.json one at a time, when it has been annotated and there is a reason to retrieve it.

To annotate one, open the annotator and pick a screen. Notes are written beside the protos and the protos themselves are never modified.
