What the local skills add to the cloud rules

  • No em dash, ever. The cloud kept 40 lines with an em dash; each one now uses a colon, period, semicolon or parentheses. None is left in any copy file.
  • British spelling. colour, customise, analyse, organise, licence, favourite, cancelled.
  • “and”, not “&”. Kept only in names such as L&D and Q&A.
  • One “…”, only while something runs. “Generating link…”; static placeholders lose the dots.
  • No generic actions or vague errors. No “Learn more”, “Get started”, “Submit”, “OK”, “Something went wrong” or “Unable to”: the error names what happened, then the next step.
  • No sell words. smart, great, premium, insights, instantly, successfully, unless it is a fixed product or tier name.
  • “you”, “people” or “members”, never “users”. Money reads “a month”, “a year”, “a seat”.
  • Sentence case; full stops only on full sentences. Toasts end with a period; buttons, tabs and labels do not.
