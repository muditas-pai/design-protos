Fast read

Three numbers, then the receipt

Leads with the three figures a buyer actually weighs (credits, per-credit price, decks a year) as big tiles with a delta line, then a one-row strip for price and cost per deck. Free is mentioned only where it matters.

  • Least table-like, scans in a second
  • Deltas live with the number, no column hunting
  • Reuses the modal's stat-tile language from How credits work

Single column

Ledger with reference captions

One plan, one column. Basic's numbers are the only big type; Free and the higher tiers appear as small grey captions under each value. No competing columns, no empty dashes for Free.

  • Cleanest for a modal that is about one plan
  • Captions can point up (Pro, Gold) as well as down (Free)
  • Header band uses the navy wash so it still reads as "Basic"

Context

Plan ladder + three facts

A tiny column chart places Basic between Free and Pro on credits, then three fact blocks carry price, per-credit and decks. Shows the buyer where they land and what the next rung looks like.

  • Makes "3x Free" and "Pro is 5x Basic" visible at once
  • Same component can drive Pro and Gold modals with the highlight moved
  • Facts row replaces the table entirely
