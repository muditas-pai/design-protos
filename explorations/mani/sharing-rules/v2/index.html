3 kinds of project, folder or file

🔒 Private
  • Only the creator
  • Not even the workspace Owner or an Admin
  • Stays private until the creator shares it
  • Exception: a widget turned on earlier keeps working updated
👥 Shared with a few people
  • Creator + the people added (e.g. Madhu and Sumanth)
  • Folder access covers every doc and sub-folder inside, including new ones
  • One doc inside can be more open, e.g. public for the team. The team then sees only that doc updated
  • Anything moved out loses that access
🌎 Public
  • Every workspace Member (edit) and workspace Viewer (read-only)
  • New joiners see it too
  • Folder or file Viewers don't see it

People

👑 Owner

  • Created the workspace
  • Must transfer ownership to an Admin before leaving updated
  • Everything an Admin can do
  • Can't see others' private items

🛠 Admin

  • Manages members, billing and removals
  • Makes other Admins. Can remove members and Admins, never the Owner updated
  • Deletes whole projects and folders updated
  • Owns shared docs of people who leave (the Owner does if there are no Admins) updated
  • Can't see others' private items

👤 Member

  • Sees and edits every public item
  • Creates new docs
  • Deletes any doc they can edit (30-day restore). Deletes a whole project or folder only if they created it (they're its owner) updated
  • Moves docs between public projects. Only the creator makes a doc private updated
  • Turns the widget on or off updated
  • Invites Members and Viewers
  • Download, export, duplicate
  • Uses the shared credit pool
  • Buys credits and Hire an expert on the workspace card updated

👁 Workspace Viewer

  • Sees every public item, read-only
  • Can comment and present updated
  • Can copy a widget link that's already on updated
  • Can't create, edit, invite, download, export, duplicate or turn the widget on
  • No credits

👁 Folder or file Viewer

  • Only that project, folder or file, read-only
  • Can comment and present updated
  • Can't create, edit, invite, download, export or duplicate
  • Can copy a widget link that's already on updated
  • Shows in Settings → Members with an "Only: Sales folder" tag

Widget link (public link)

🌍 Widget, like a YouTube link

  • On every plan
  • Anyone with the link watches and presents, with no sign up
  • Post it anywhere: Twitter, LinkedIn, a website
  • "Export as PowerPoint" is always there. The viewer signs up and pays. The owner pays nothing
  • What the viewer pays depends on their country updated: 🇺🇸 USA sees plans only (unlimited exports). 🌍 Other countries see both: a one-time export per file (buy as often as they like) or a plan
  • The owner can't turn export off
  • Anyone with edit access (Members) turns it on or off. Viewers can only copy a link that's already on updated
  • Making the doc private keeps the widget live. Deleting the doc kills it, and restoring doesn't turn it back on updated
  • Turning the widget on warns: "Anyone with this link can view it and buy a PowerPoint copy"

Other rules

🔀 Moving

Access follows the folder. Warn on every move that changes access: private → public, public → private, and out of a shared folder ("Priya will lose access").

⬆️ Viewer → Member

The Owner or any Member upgrades in one click. No 200 credits, because the account already exists.

⚖️ Two roles on one item

The higher role wins.

⚡ Removing access

Applies right away, even if the doc is open. updated

🚪 Member leaves

Public and shared docs stay, and an Admin becomes the owner (the Owner, if there are no Admins). Private docs are deleted: hidden 30 days, back only if the same person rejoins, then gone. Nobody else can open them.

🗑 Delete

Members delete any doc they can edit. Kept 30 days. The owner gets "Sara deleted Q4 Pitch. Restore?" and the trash shows "Deleted by Sara". updated

🪙 Credits

One shared pool per workspace. Free workspaces also get the invite bonus.

🗂 Projects and folders

Only the creator or an Admin deletes a whole project or folder. Others can "Leave" a shared one. Public projects can't be left. updated

📄 Duplicates

Copy goes next to the original if you can edit there, else your private space. Only slides are copied: no invites, comments or widget. updated

📥 Exports and Hire an expert

Only the person who exported or ordered sees the file. Hire an expert sends the expert a copy, never workspace access. updated

💳 Purchases

On paid plans, any Member buys credits and Hire an expert on the workspace card. No limit. Free workspaces can't buy. updated

🪫 Credit pool

No per-person limit. The Owner is alerted when the pool is 80% used. updated

↩️ Refunds and payment

Refunds by email to support, back to the card that paid, unspent credits only. Paid plan payment fails: read-only right away. No downgrade from Team. updated

⬆️ Upgrading to Team

Members, files and roles carry over. Unused bonus credits stay. The invite bonus stops. updated

👤 Member → Viewer

The Owner or an Admin can do it. Bonus credits already earned stay. updated

👑 Owner transfer

To an Admin. For a free workspace, blocked if that person already owns one. Owner unreachable: contact support. updated

🏷 Team settings

Auto-join by company email (the Admin picks: join as Member or Viewer) and Block outside sharing. Both off by default. updated

✉️ Invites

Expire after 14 days. Resend restarts the clock. Revoke anytime. updated

📥 Shared with me

A sidebar tab listing every folder and file shared with you, and who shared it. updated

🔔 Emails

On share and on @mention. Everything else is in-app. Plus the "Deleted by" alert. updated

👯 Editing together

Live co-editing. Everyone sees each other's cursors. updated

🕘 Version history

Coming later. updated

👤 File owner

Whoever creates a file owns it for good. No handing over. Only exception: when someone leaves, an Admin (or the Owner) takes their shared docs. updated

✏️ Renaming

Only the creator or an Admin renames a project or folder. updated

🔁 Many workspaces

Fully separate: own files, members and credits. Switch from the top. Files can't move between workspaces. updated

💥 Deleting the workspace

Only the Owner, after typing its name. Paid plan cancelled, everyone emailed, kept 30 days, then gone. updated

Who can see and do what 🧒

The super simple version of v2. Every rule is here, in plain words.

🏠 1. It's like a house

🏠Workspacethe house
→
🚪Folder or projecta room (rooms can have rooms inside)
→
📄Filea page

Mani built the house called Formula One. So Mani is the boss (the Owner).

👥 2. The people

👑

Owner

Built the house. Can do everything a helper can. Must give the house to a helper before leaving.

🛠

Admin

The boss's helper. Adds and removes people, and can make more helpers. Can never remove the Owner.

✏️

Member

On the team. Sees every public room, changes things, makes new pages, invites people.

👀

Viewer

Only looks. Can leave comments and present. Can't change anything.

🙈 Nobody can see your private stuff. Not the Owner, not the helpers.

⭐ 3. The two golden rules

✏️ A Member always joins the whole house. Even if you invite them to one room, they see every public room.
👀 A Viewer only sees what you give them. One room = only that room. One page = only that page.

When you pick Member for one room, we warn you: "Bala will see all public rooms. Pick Viewer to share only this room."

🚪 4. Three kinds of rooms

🔒

Private

Only you.

👥

Shared

You plus the people you pick.

🌎

Public

Everyone in the house.

If a room is shared, everyone in it also sees new pages and rooms you add later. Take a page out of the room, and they lose it (we warn you first).

🪆 Rooms can have rooms inside them. An inside room or page can be more open than the room around it, but never more secret.

🎟 5. Plans

🆓

Free

One free house per person. Invite as many people as you want. Get 200 credits each time a new person makes an account, checks their email and joins. Up to 1,000. You can't buy more credits on Free. Upgrading later: alone = any plan, with other people = Team only.

👤

Basic, Pro, Gold

Just you. To invite anyone, upgrade to Team.

👥

Team

Invite everyone. The whole team shares one big pot of credits.

It's like a YouTube link. Anyone in the world can watch your deck, without signing up. Every plan has it.
