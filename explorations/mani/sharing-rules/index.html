Share, Invite and Collaboration: final rules

Every decision from the review, in one diagram. Purple "proposed" = not confirmed yet.

🏢 Foursquare workspace
🌎 Public Project
Who gets in, and what they can do:
  • Every member, including new joiners
  • Every member can create, view, edit, delete and restore docs
  • Guests: only the docs they're invited to
  • Only the doc owner can make a doc private. It moves to the owner's private space, invited people keep access
  • Delete shows "Deleted by" and alerts the owner proposed
  • Only the project creator or an admin can rename, delete or make the project private proposed
🔒 Private Project
Who gets in, and what they can do:
  • Owner
  • Members added as Editor (can add docs), Commenter or Viewer
  • Covers every doc inside it. To hide a doc, move it out
  • A doc inside can be shared with extra people (add, never remove) proposed
  • Shared with everyone → becomes Public Project
  • Guests: only the docs they're invited to
🔒 Private Doc
Who gets in, and what they can do:
  • Owner
  • Members added as Editor, Commenter or Viewer
  • Guest Editor or Guest Viewer
  • Public link (view only): only the owner can turn it on. Doc shows a "🔗 Public link on" badge proposed
  • Never "everyone in workspace". Move it to a Public Project instead
  • Admin can't open it

People

👑 Workspace owner

  • Everything an admin can do
  • Must transfer ownership before leaving

🛠 Admin

  • Approves new members
  • Removes members
  • Auto-join setting (off by default)
  • Block outside sharing (enterprise)
  • Buys AI credits
  • Only admins see the Settings invite link proposed
  • Can't open private docs

👤 Member

  • Creates own docs
  • Sees and edits all Public Projects
  • Editor, Commenter or Viewer on private docs and projects
  • Editors can invite, unless owner turns on "Only I can share"
  • Can't give a higher role than their own proposed
  • Can transfer a doc they own to another member proposed

✏️ Guest Editor

  • Only the invited doc
  • Edit, add slides, comment, present
  • Apply brand kit (not edit it)
  • Uses workspace AI credits
  • No download, export, duplicate, invite or delete

👁 Guest Viewer

  • Only the invited doc
  • View and present
  • No download, comment or invite

Both guest types: must sign up, are free, and count toward the plan limit (Free 2, Pro 5, Gold 10, Team 5 per seat). The limit counts people, not docs. Guests can't create or copy share links proposed. Upgraded to member = keeps their docs, frees the guest slot, uses a paid seat proposed.

Ways in (everyone signs up)

✉️ Email invite

Guest invite = guest, no admin step. Member invite = Guest Editor until the admin approves (if declined, stays guest). Expires in 14 days, can resend or revoke.

🔗 Doc link

Only the owner and Editors create links. Role: Guest Editor, Guest Viewer or Member (Member waits for admin approval). "Only invited people" by default. "Anyone with the link" is view only, and those viewers don't count as guests proposed. Reset stops the old link, people already in keep access.

⚙️ Settings invite link

From Settings → Members, admins only proposed. Whoever joins becomes a workspace member.

🏷 Auto-join

Company email joins, if the admin turns it on. Admin picks: join right away or wait for approval.

Other rules

🚪 Member removed

Unshared private docs deleted (back within 30 days if they rejoin). Shared docs stay in "Shared with me", first member Editor becomes owner (never a guest), else admin. Leaving on your own works the same way. Projects stay, admin becomes owner.

👑 Owner leaves

Must transfer workspace ownership to another admin first.

🔀 Move or share

Always warns when access changes. No subprojects. No "Request access": private stays private.

📄 Copy and delete

Copy goes next to the original if you can add docs there, else to your private space. Deleted docs kept 30 days, anyone with edit access restores.

Edge cases proposed

SituationWhat happens
Role changed while the person has the doc openApplies right away. An Editor turned Viewer goes read-only mid-session.
Person removed from a doc while it's openDoc closes with "You no longer have access".
Invite someone who already has accessTheir role on that doc updates. No duplicate invite.
Guest accepts a member invite, or auto-joins by company emailGuest becomes a member and keeps their docs.
Doc with guests moves into a Public ProjectGuests keep access to that doc only. They never see the rest of the project.
Doc or project deletedEveryone loses access, guests included. Restoring within 30 days brings the same access back.
Moving a doc between projectsAny member can move docs between Public Projects. Only the doc owner can move a doc into a private space.
Plan downgraded below the guest countExisting guests stay. No new guests until the count is under the new limit.
Admin turns on "Block outside sharing" while outside guests existWarning shows the count. Outside guests and public links stop working.
Inviter leaves while their "Member" invite waits for approvalThe request stays in Settings → Members → Pending for the admin.
Doc owner wants to hand a doc to someoneTransfer to a workspace member only, never to a guest. One owner per doc.
Guest wants to create their own decksThey use their own personal workspace. Foursquare docs only show in their "Shared with me".
Doc shared with a memberShows in their "Shared with me" and in its project, if they can see the project.
Guest Editor makes a mistakeOnly normal undo for now. Version history comes later.
Workspace credits run out while a member uses AISame popup as guests: "Contact your admin to buy more". Admins see "Buy credits".
