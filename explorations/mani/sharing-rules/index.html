🌎 Public Project
Who gets in, and what they can do:
  • Every member, including new joiners
  • Every member can create, view, edit, delete and restore docs
  • Only the doc owner can make a doc private. It moves to the owner's private space, invited people keep access
  • Delete shows "Deleted by" and alerts the owner
  • Only the project creator or an admin can rename, delete or make the project private
🔒 Private Project
Who gets in, and what they can do:
  • Owner
  • Members added as Editor (can add docs) or Commenter
  • Covers every doc inside it. To hide a doc, move it out
  • Project access can't be changed on a doc inside it: no removing people, no raising or lowering their role. A doc can only add new people updated
  • Shared with everyone → becomes Public Project. Only the project owner can do this updated
  • Only the owner deletes docs or the project. Editors can't updated
🔒 Private Doc
Who gets in, and what they can do:
  • Owner
  • Members added as Editor or Commenter
  • Share with everyone in workspace, as Editor or Commenter. Shows in their "Shared with me". Works for private docs inside private projects too
  • Only the owner can delete it or move it into a Public Project updated
  • Admin can't open it

Ways in to work on a doc (everyone signs up)

✉️ Email invite

Invites a person with Editor or Commenter on that doc. Already a member: access right away. New to the workspace: they wait for admin approval and see a "waiting for approval" screen. Invites sent by the Owner or an Admin skip approval. Expires in 14 days, can resend or revoke.

🔗 Invite link

Gives Editor or Commenter on that doc. People new to the workspace wait for admin approval, same as email invites. Works only for invited people. Only the owner and Editors create it. Reset stops the old link, people already in keep access

⚙️ Settings invite link

From Settings → Members, admins only. Whoever joins becomes a workspace member right away, no approval, because an admin created the link. Expires after 7 days and can be reset anytime updated.

🏷 Auto-join

Company email joins, if the admin turns it on. Admin picks: join right away or wait for approval.

Public link

🌍 Public link (like a YouTube link)

  • From the Share modal, on any doc, on every plan
  • Anyone in the world can watch. No sign up, no login
  • This is the only way to share view-only. There are no Viewer roles
  • View and present only. Can be embedded like a widget
  • Not a member. They don't join anything or show in any list
  • The doc owner and everyone the doc is shared with (Editors and Commenters) can turn it on or off updated
  • Admin setting: turn public links off for the whole workspace updated
  • No download from the public link
  • Turning it off stops the link for everyone

Other rules

🚪 Member removed

Unshared private docs deleted (back within 30 days if they rejoin). Shared docs (with people or with the whole workspace) stay in "Shared with me", first member Editor becomes owner, else admin. Leaving on your own works the same way. Shared projects stay, admin becomes owner. Unshared private projects are deleted with the docs. Invites they sent stay valid.

👑 Owner leaves

Must transfer workspace ownership to another admin first. No other admin? Make a member admin first. The owner can't be removed by admins.

🔀 Move or share

Always warns when access changes. No subprojects. No "Request access": private stays private.

📄 Copy and delete

Copy goes next to the original if you can add docs there, else to your private space. Deleted docs kept 30 days. Any member restores in a Public Project, only the owner on private docs and projects. updated

Billing and purchases

💳 Whose card

Owner and Admins pay with the workspace card. Every other member pays with their own card. Members never see the workspace card. updated

🪙 Credits

Everything bought goes into one shared workspace pool. Credits stay in the workspace when someone leaves.

📥 Exports and expert orders

Only the person who exported or ordered sees the file, in their own Downloads, even for decks in a Public Project. Owner and Admins see only the billing line.

↩️ Refunds and disputes

Email to support only, no option in the app. Money goes back to the card that paid. Only unspent credits are refunded.
