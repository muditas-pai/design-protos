Share, Invite and Collaboration: final rules

Every decision from the review, in one diagram. Purple "proposed" = not confirmed yet.

Plans updated

👤 Basic · Pro · Gold single user

  • ✅ Private and Public Projects, "Everyone in workspace" (ready for when the team grows)
  • ✅ Guest Editor, Guest Viewer and public link
  • ❌ Inviting a workspace member → "Upgrade to Team to invite members"

👥 Team unlimited licences

  • ✅ Everything on this page
  • ✅ Unlimited members and unlimited guests
  • ✅ One shared pool of AI credits for members and guests
🏢 Foursquare workspace
🌎 Public Project
Who gets in, and what they can do:
  • Every member, including new joiners
  • Every member can create, view, edit, delete and restore docs
  • Guests: only the docs they're invited to
  • Only the doc owner can make a doc private. It moves to the owner's private space, invited people keep access
  • Delete shows "Deleted by" and alerts the owner proposed
  • Only the project creator or an admin can rename, delete or make the project private proposed
🔒 Private Project
Who gets in, and what they can do:
  • Owner
  • Members added as Editor (can add docs), Commenter or Viewer
  • Covers every doc inside it. To hide a doc, move it out
  • A doc inside can be shared with extra people (add, never remove) proposed
  • Shared with everyone → becomes Public Project
  • Guests: only the docs they're invited to
🔒 Private Doc
Who gets in, and what they can do:
  • Owner
  • Members added as Editor, Commenter or Viewer
  • Guest Editor or Guest Viewer
  • Share with everyone in workspace. Shows in their "Shared with me". Works for private docs inside private projects too updated
  • Admin can't open it

People

👑 Workspace owner

  • Everything an admin can do
  • Must transfer ownership before leaving

🛠 Admin

  • Approves new members
  • Removes members
  • Auto-join setting (off by default)
  • Block outside sharing
  • Buys AI credits
  • Only admins see the Settings invite link proposed
  • Can't open private docs

👤 Member

  • Creates own docs
  • Sees and edits all Public Projects
  • Editor, Commenter or Viewer on private docs and projects
  • Editors can invite and create links, unless owner turns on "Only I can share" (blocks both) updated
  • Can't give a higher role than their own proposed
  • Can transfer a doc they own to another member proposed

✏️ Guest Editor

  • Only the invited doc
  • Edit, add slides, comment, present
  • Apply brand kit (not edit it)
  • Uses workspace AI credits
  • No download, export, duplicate, invite or delete

👁 Guest Viewer

  • Only the invited doc
  • View and present
  • No download, comment or invite

Both guest types: must sign up for a free account (no paid plan needed) and see only the docs they are invited to. Guests can't create or copy share links. Guest Editor and Guest Viewer work on every plan. A guest who becomes a member keeps their docs (no extra cost, Team is unlimited) updated

Ways in to work on a doc (everyone signs up)

✉️ Email invite

Guest invite = guest, no admin step. Member invite = Guest Editor until the admin approves (if declined, stays guest). Approval stays on Team too, so the admin controls who joins updated. Expires in 14 days, can resend or revoke.

🔗 Invite link

Gives a role: Guest Editor, Guest Viewer or Member (Member waits for admin approval). Works only for invited people. Only the owner and Editors create it. Reset stops the old link, people already in keep access updated

⚙️ Settings invite link

From Settings → Members, admins only proposed. Whoever joins becomes a workspace member.

🏷 Auto-join

Company email joins, if the admin turns it on. Admin picks: join right away or wait for approval.

Public link updated

🌍 Public link (like a YouTube link)

  • From the Share modal, on any doc, on every plan
  • Anyone in the world can watch. No sign up, no login
  • View and present only. Can be embedded like a widget
  • Not a member or guest. They don't join anything or show in any list
  • Owner and Editors turn it on or off (blocked by "Only I can share")
  • Turning it off stops the link for everyone

Other rules

🚪 Member removed

Unshared private docs deleted (back within 30 days if they rejoin). Shared docs (with people or with the whole workspace) stay in "Shared with me", first member Editor becomes owner (never a guest), else admin. Leaving on your own works the same way. Shared projects stay, admin becomes owner. Unshared private projects are deleted with the docs. Invites they sent stay valid. updated

👑 Owner leaves

Must transfer workspace ownership to another admin first. No other admin? Make a member admin first. The owner can't be removed by admins. updated

🔀 Move or share

Always warns when access changes. No subprojects. No "Request access": private stays private.

📄 Copy and delete

Copy goes next to the original if you can add docs there, else to your private space. Deleted docs kept 30 days, anyone with edit access restores.
