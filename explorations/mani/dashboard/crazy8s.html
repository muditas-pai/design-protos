Get most out of Pro · outline animation handoff

Four candidates on the 4px-corner button. Copyable CSS under each one, dev notes below.

How it works (read once before copying)

  • Technique. The moving light is a conic-gradient painted on an absolutely positioned pseudo-element behind the button, masked down to a thin band with a two-layer mask + mask-composite: exclude. The rotation animates a registered custom property --a (via @property), so the gradient angle tweens smoothly. Corners are followed exactly; no SVG needed.
  • Shape coupling. The pseudo sits at inset: -2px with padding: 2px (band thickness) and border-radius: button radius + 2px. If the button radius changes, change the ring radius with it.
  • Support. Chrome/Edge 85+, Safari 16.4+, Firefox 128+. Older browsers just show no ring; the button itself is unaffected. Keep the -webkit-mask prefixed lines.
  • Performance. Animation is paint-only on a small layer, no layout. One instance per page is effectively free.
  • Motion safety. Disable under prefers-reduced-motion: reduce (included in each snippet).
  • Color tokens. Brand Blue #005EFF, tint #E6EFFF, translucent stops rgba(0,94,255,α). Do not introduce other hues.
  • Markup contract. Wrap the existing button in a positioned wrapper (.wrap) and put the ring class on the wrapper. No changes inside the button DOM.
01 · Comet tail
CSS for devs 
<div class="wrap comet">
  <button class="pro-btn">…</button>
</div>

/* animated angle */
@property --a { syntax: '<angle>'; initial-value: 0deg; inherits: false; }
@keyframes spin { to { --a: 360deg; } }

.wrap { position: relative; display: inline-flex; }
.comet::before {
  content: ''; position: absolute; inset: -2px;
  border-radius: 6px;            /* button radius 4px + 2px inset */
  padding: 2px;                  /* band thickness */
  pointer-events: none;
  -webkit-mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude;
  background: conic-gradient(from var(--a),
    transparent 0deg, transparent 250deg,
    rgba(0,94,255,0) 260deg, rgba(0,94,255,0.55) 320deg,
    #005EFF 352deg, #E6EFFF 360deg);
  animation: spin 3s linear infinite;
}

@media (prefers-reduced-motion: reduce) {
  .comet::before { animation: none; }
}

04 · Comet + living gradient
CSS for devs 
/* Comet tail ring (variant 01) PLUS a slow drift on the button fill.
   The gradient is oversized then eased side to side. */
.pro-btn--living {
  background: linear-gradient(90deg, #ccdcfd 0%, #dfe9fe 30%, #f3f6fe 55%,
                              #fdfdfe 70%, #dfe9fe 100%);
  background-size: 250% 100%;
  animation: bg-drift 7s ease-in-out infinite;
}
@keyframes bg-drift {
  0%, 100% { background-position: 0% 0; }
  50%      { background-position: 100% 0; }
}

@media (prefers-reduced-motion: reduce) {
  .pro-btn--living { animation: none; }
}
