Notes for implementation

1. Label text is always white. Everything under the label sits at or below #2A75F6, which holds 4.2:1 or better on white type; the light tail lives in the trailing padding only.
2. Keep all nine stops. They are what make the tail read as a smooth ease instead of a hard edge; collapsing them to three brings the band back.
3. The pill's arrow tip is the same color as the 100% stop by design. If the end stop ever changes, change the tip with it.
4. Derived from the design system token gradient-brand-03 (brand/100, 300, 600, 900). If that ramp changes, re-derive rather than patching stops ad hoc.
