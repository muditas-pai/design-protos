# explorations

Everyone's playground — most prototyping happens here. Group your work by **problem statement**
(you'll usually do 8–10 variations of the same problem — keep them together):

```
explorations/<your-name>/<problem-statement>/<short-kebab-name>.html
```

Anything goes. Commit straight to `main` for an instant shareable Pages link. Reuse components
by **duplicating** (from a key screen or another frame) — don't edit someone else's files.

Start a new proto from `design-system/template.html`, and remember the design-system paths are
relative to the repo root (e.g. `../../../design-system/pai.css` from
`explorations/<you>/<problem>/`).
