# explorations

Everyone's playground — most prototyping happens here. Keep your work in your own subfolder:

```
explorations/<your-name>/<short-kebab-name>.html
```

Anything goes. Commit straight to `main` for an instant shareable Pages link. Reuse components
by **duplicating** (from a key screen or another frame) — don't edit someone else's files.

Start a new proto from `design-system/template.html`, and remember the design-system paths are
relative to the repo root (e.g. `../../design-system/pai.css` from `explorations/<you>/`).
